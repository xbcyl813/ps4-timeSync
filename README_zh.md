### 📖 项目简介
**ps4-timeSync (PKG 版)** 是一款专为越狱环境下的 **PS4 / PS4 Pro** 设计的独立自制桌面应用（`.pkg` 安装包），可通过 UDP 从公共 NTP 服务器自动校对时间。*(如需开机全自动后台运行的 GoldHEN 插件版 `.prx`，请切换至仓库的 **`main`** 分支。)*

**核心用途：**
* **免电脑、免配置一键对时：** 在主机主界面点一下图标即可校对时间。
* **免拆机替代失效的主板 CMOS 电池：** 解决断电后时间归零问题。
* **修复奖杯时间戳异常：** 避免奖杯时间显示为 `1970` 年。

### ✨ 功能特性
* **一键启动、自动退出：** 弹出通知后约 2 秒自动退出返回主界面。
* **全固件通用兼容：** 兼容 `5.05`、`6.72`、`7.xx`、`9.00`、`11.00` 等主流固件。
* **双服务器容灾：** 直连阿里云 NTP（`203.107.6.88`），失败自动切换腾讯云 NTP（`119.29.26.206`）。

### 🚀 安装与使用方法
1. 从 **Actions**（`pkg` 分支）或 **Releases** 页面下载编译好的 `.pkg` 文件。
2. 放入 **exFAT/FAT32** U 盘根目录，通过 **GoldHEN -> Package Installer** 安装。
3. 确保 PS4 联网并设置好本地时区。
4. 在主界面启动 **ps4-timeSync**，弹窗提示成功后程序将自动退出。
